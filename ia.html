1. C’est quoi l’intelligence artificielle ?

L’IA regroupe les techniques qui permettent à une machine d’accomplir des tâches qui demandent d’habitude de l’intelligence humaine : reconnaître une image, comprendre une phrase, recommander un film. Ce sont des poupées russes : cliquez sur chaque niveau.

Programmation classique

Vous écrivez les règles. si mail contient « gratuit » alors spam. Facile à comprendre, mais impossible à maintenir pour des milliers de cas.

Machine Learning

Vous donnez des exemples et la machine déduit les règles elle-même. C’est la grande différence.

3. Comment développer une IA

Un projet d’IA suit toujours le même cycle. Cliquez sur une étape.

Le même cycle en 8 lignes de Python

from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LogisticRegression

mails  = ["gagner gratuit", "réunion rapport", "cliquez gratuit", "facture réunion"]
labels = [1, 0, 1, 0]                       # 1 = spam
vec = CountVectorizer(); X = vec.fit_transform(mails)
model = LogisticRegression().fit(X, labels)  # entraînement
print(model.predict(vec.transform(["cliquez pour gagner"])))  # prédiction
Outils à connaître : Python, scikit-learn (ML classique), PyTorch ou TensorFlow (deep learning), Hugging Face (modèles prêts à l’emploi), Jupyter / Colab (pour expérimenter).

4. Comment l’IA comprend le texte : tokens et vecteurs

Un modèle ne lit pas des lettres. Il découpe en tokens, puis transforme le texte en vecteur (une liste de nombres) qui représente le sens. Des textes de sens proche donnent des vecteurs proches.

Tokenisation (simulée) à essayer

Identifiants fictifs ; un vrai tokenizer découpe autrement.

Recherche sémantique (comme votre chatbot) à essayer

La question est vectorisée, puis comparée à chaque réponse par similarité cosinus (proche de 1 = même sens).

Attention : ce ne sont pas des cases lisibles. « 0.82 » ne veut pas dire « chat » : le sens est porté par tout le vecteur, calculé par un réseau de neurones entraîné.

$ch = curl_init('https://api.anthropic.com/v1/messages');
curl_setopt_array($ch, [
  CURLOPT_HTTPHEADER => ['content-type: application/json',
      'x-api-key: ' . getenv('API_KEY'), 'anthropic-version: 2023-06-01'],
  CURLOPT_POSTFIELDS => json_encode([
      'model' => 'claude-sonnet-5', 'max_tokens' => 500,
      'messages' => [['role' => 'user', 'content' => $prompt]]]),
  CURLOPT_RETURNTRANSFER => true, CURLOPT_POST => true]);
$reponse = json_decode(curl_exec($ch), true);


Ne mettez jamais la clé API dans le code source ni dans le navigateur : utilisez une variable d’environnement côté serveur.


C. Donner vos propres documents à l’IA : le RAG


  1. Vous découpez vos documents en morceaux et calculez leurs vecteurs (une fois)
  2. L’utilisateur pose une question
  3. La question est vectorisée
  4. Les morceaux les plus proches (cosinus) sont retrouvés
  5. Ils sont ajoutés au prompt du modèle
  6. Le modèle répond en s’appuyant sur vos documents





6. Les limites à connaître




Hallucinations
Le modèle peut affirmer avec assurance quelque chose de faux. Vérifiez les faits importants.


Biais
Il reproduit les biais des données d’entraînement.


Vie privée
N’envoyez pas de données personnelles ou confidentielles sans cadre clair.


Responsabilité
L’IA assiste, l’humain décide et signe. Citez l’usage de l’IA dans vos travaux.


À retenir : l’IA apprend des règles à partir d’exemples ; on la développe par un cycle données ➜ entraînement ➜ évaluation ➜ déploiement ; on l’utilise avec des prompts précis, en vérifiant toujours le résultat.
