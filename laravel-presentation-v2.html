1. Qu'est-ce que Laravel ?

Laravel est un framework PHP open source, créé par Taylor Otwell en 2011. Un framework, c'est une ossature de code déjà construite : au lieu de partir d'une page blanche, vous héritez d'une structure solide (routage, sécurité, base de données, emails, files d'attente…) et vous vous concentrez sur la logique propre à votre projet.

4. L'architecture MVC

Laravel suit le modèle MVC (Modèle-Vue-Contrôleur). Cliquez sur une étape pour la détailler.

mon-projet/
  app/
    Http/Controllers/ ← vos contrôleurs
    Models/ ← vos modèles Eloquent
  routes/web.php ← toutes vos URLs
  resources/views/ ← vos fichiers Blade (.blade.php)
  database/migrations/ ← structure des tables
  .env ← configuration (base de données, clés API…)

5. Mini-tutoriel : afficher une liste depuis la base de données

1
Créer une migration et un modèle
$ php artisan make:model Formation -m
2
Définir la table dans la migration 
Schema::create('formations', function (Blueprint $table) {
    $table->id();
    $table->string('titre');
    $table->integer('duree_heures');
    $table->decimal('prix', 8, 2);
    $table->timestamps();
});
3
Exécuter la migration
$ php artisan migrate
4
Ajouter une route 
Route::get('/formations', [FormationController::class, 'index']);
5
Écrire le contrôleur 
public function index()
{
    $formations = Formation::all(); // Eloquent : pas de SQL à écrire
    return view('formations.index', compact('formations'));
}
6
Créer la vue Blade 
@foreach ($formations as $formation)
    <p>{{ $formation->titre }} — {{ $formation->duree_heures }}h — {{ $formation->prix }} DT</p>
@endforeach
✅ En 6 étapes, sans écrire une seule requête SQL, vous avez une page qui liste vos formations depuis la base de données.

7. Laravel et l'intelligence artificielle

Ce que vous avez appris avec PHP pur (embeddings, similarité cosinus, appel à une API IA) s'applique directement dans Laravel — en plus propre.

🔌 Appeler une API IA avec le client HTTP de Laravel 
use Illuminate\Support\Facades\Http;

$reponse = Http::withHeaders([
        'x-api-key' => config('services.anthropic.key'),
        'anthropic-version' => '2023-06-01',
    ])->post('https://api.anthropic.com/v1/messages', [
        'model' => 'claude-sonnet-5',
        'max_tokens' => 300,
        'messages' => [['role' => 'user', 'content' => $prompt]],
    ]);

$texte = $reponse->json('content.0.text');

Plus besoin de curl_init() à la main : le facade Http fait tout, et la clé API reste dans .env.
