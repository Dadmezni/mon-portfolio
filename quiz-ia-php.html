Le cours en bref

L’IA apprend des régularités à partir de données. Un embedding représente le sens d’un texte sous forme de vecteur. Dans un système RAG, PHP peut retrouver des documents pertinents avec une base de données, puis transmettre leur contenu à un modèle génératif. Le modèle produit une réponse ; il faut la vérifier.
