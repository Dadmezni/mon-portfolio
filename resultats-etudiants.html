Comment regrouper les réponses de tous les étudiants ? (site statique)

Le navigateur ne peut pas écrire dans un fichier du serveur Render. Chaque réponse est donc :

  1. gardée dans le navigateur de l'étudiant (localStorage) ;
  2. envoyée par e-mail à l'enseignant via Formspree (le champ json contient le résultat complet).

Pour tout voir dans ce tableau : collez ci-dessous le contenu des champs json reçus par e-mail (un objet, une liste, ou plusieurs objets un par ligne), ou importez un fichier. Cliquez ensuite sur Exporter JSON et placez le fichier dans votre dépôt sous data/resultats.json : cette page le charge automatiquement au prochain déploiement.

Attention : cette page est publique (site statique). N'importe qui connaissant l'adresse peut la voir ; ne publiez pas data/resultats.json si les notes sont confidentielles.
