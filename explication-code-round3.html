Vue d'ensemble

Ce fichier fait une seule chose : recevoir une question tapée dans un formulaire, et afficher à quel point chacun des 3 documents lui ressemble. C'est le Round 3 de votre histoire — la recherche sémantique.

🧭 Le fichier contient 4 morceaux : une fonction de calcul (cosineSimilarity), une fonction qui simule un embedding (getEmbeddingSimule), une liste de documents, puis le formulaire HTML qui utilise tout ça.

Bloc 1 — cosineSimilarity() : mesurer une ressemblance

1function cosineSimilarity(array $a, array $b): float
2{
3    $dot = $normA = $normB = 0.0;
4    foreach ($a as $i => $x) {
5        $dot   += $x * $b[$i];
6        $normA += $x * $x;
7        $normB += $b[$i] * $b[$i];
8    }
9    return ($normA && $normB) ? $dot / (sqrt($normA) * sqrt($normB)) : 0.0;
10}

Ce que fait chaque ligne

LigneExplication
array $a, array $bLa fonction attend deux vecteurs (deux tableaux de nombres) à comparer.
: floatElle renverra toujours un nombre décimal (le score).
$dot = $normA = $normB = 0.0;Trois compteurs à zéro, remplis pendant la boucle.
foreach ($a as $i => $x)On parcourt le vecteur $a ; $i est la position (0, 1, 2…), $x est la valeur à cette position.
$dot += $x * $b[$i]On multiplie les nombres à la même position dans les deux vecteurs, et on additionne au fil de la boucle — c'est le produit scalaire.
$normA += $x * $xOn additionne le carré de chaque nombre de $a — pour calculer sa « longueur ».
return (...) ? ... : 0.0;Un raccourci d'écriture (opérateur ternaire) qui veut dire : si les deux normes ne sont pas nulles, on divise ; sinon, on renvoie 0 pour éviter une division par zéro.
🌍 Analogie : imaginez deux flèches partant du même point. Le score cosinus mesure si elles pointent dans la même direction (proche de 1), perpendiculaires (proche de 0), ou opposées (proche de -1) — peu importe leur longueur.

Bloc 2 — getEmbeddingSimule() : deviner un vecteur à partir de mots

1function getEmbeddingSimule(string $texte): array
2{
3    $texte = strtolower($texte);
4    if (str_contains($texte, "durée") || str_contains($texte, "dure")
5        || str_contains($texte, "heures") || str_contains($texte, "temps")) {
6        return [0.76, 0.19, -0.27, 0.80];
7    }
8    if (str_contains($texte, "prix") || ...) {
9        return [-0.58, 0.22, 0.68, 0.18];
10    }
11    if (str_contains($texte, "apprend") || ...) {
12        return [0.28, 0.73, 0.38, -0.08];
13    }
14    return [0, 0, 0, 0];
15}

Ce que fait chaque ligne

LigneExplication
strtolower($texte)Met le texte en minuscules, pour que « Durée » et « durée » soient traités pareil.
str_contains($texte, "durée")Teste si le mot « durée » apparaît dans le texte, peu importe où.
|| str_contains(...)« OU » : si n'importe lequel de ces mots est présent, la condition est vraie.
return [0.76, 0.19, -0.27, 0.80];Un vecteur fixe, préparé à l'avance, qu'on renvoie dès qu'un des mots de la catégorie « durée » est détecté.
return [0, 0, 0, 0];Si aucun mot connu n'a été trouvé, on renvoie un vecteur neutre.
⚠️ À bien faire comprendre : ceci n'est pas un vrai modèle d'IA. Un vrai modèle calcule le vecteur à partir du sens de la phrase entière, pas d'une simple recherche de mots. Cette fonction imite le résultat pour que le TP fonctionne sans clé API.

Ce que fait chaque ligne

$documents est un tableau de tableaux : une liste, où chaque élément est lui-même un petit tableau avec deux informations — le texte (contenu) et son vecteur déjà calculé (vecteur).

Bloc 5 — e() : la fonction de sécurité

1function e(string $s): string
2{
3    return htmlspecialchars($s, ENT_QUOTES, 'UTF-8');
4}

Pourquoi cette fonction existe

Avant d'afficher un texte tapé par l'utilisateur dans la page, on doit le « nettoyer ». Sans ça, quelqu'un pourrait taper du code HTML ou JavaScript dans le champ, qui s'exécuterait dans la page — une faille appelée XSS. htmlspecialchars() transforme les caractères dangereux (<, >, "…) en texte inoffensif.

Règle à retenir : tout texte venant de l'utilisateur ($_POST, $_GET…) doit passer par e() avant d'être affiché dans le HTML.
