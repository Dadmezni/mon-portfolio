1Comprendre le projet

Savoir ce que l'on va construire.

Un portfolio est un site personnel qui montre qui vous êtes, ce que vous savez faire et la preuve (vos projets). Sections visées : navbar, présentation, à propos, compétences, projets, formation, contact, footer.

9Publier avec GitHub Pages

Obtenir une URL publique.

  1. Dans le dépôt : Settings.
  2. Menu de gauche : Pages.
  3. Source : Deploy from a branch.
  4. Branch : main, dossier / (root), puis Save.
  5. Attendez 1 à 3 minutes et actualisez : l'URL apparaît.
Erreur 404 ? Vérifiez que le dépôt est public et que index.html est bien à la racine.

10Projet final et vérification

Rendre un portfolio complet.

  • Toutes les sections sont présentes et personnalisées.
  • Au moins 3 projets en cartes, avec liens.
  • Images avec alt, burger testé, liens testés.
  • Au moins 8 commits, messages clairs.
  • Dépôt public, README complet avec l'URL de démo.
  • GitHub Pages actif.

À rendre : l'URL du dépôt et l'URL GitHub Pages.

Mon image ne s'affiche pas

Vérifiez le chemin (img/photo.jpg), les majuscules/minuscules et l'extension réelle du fichier.

Le menu burger ne s'ouvre pas

Le script bootstrap.bundle.min.js est absent ou placé avant le reste de la page.

Git refuse le push

Vérifiez l'URL avec git remote -v et votre authentification (token ou connexion GitHub dans VS Code).

GitHub Pages affiche une erreur 404

Dépôt public ? Branche main ? index.html à la racine ? Attendez quelques minutes.

Mon style Bootstrap ne s'applique pas

Le lien CDN est mal copié, ou votre style.css est chargé avant Bootstrap.
