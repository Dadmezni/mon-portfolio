🧭Introduction à Bootstrap

Concept. Bootstrap est une bibliothèque CSS (et JS) de composants et d'utilitaires prêts à l'emploi : on assemble une interface avec des classes au lieu de tout écrire en CSS. Analogie : des briques Lego déjà moulées.

⚙️Installation et configuration

CDN (débutant) : deux lignes, aucune installation.

NPM + Vite (professionnel) : versions figées, import sélectif, Sass possible.

📌 À retenir : CDN pour apprendre, npm + Vite pour un vrai projet. Le bundle inclut Popper.

🧱Le système de Grid

Concept. Une ligne (row) = 12 colonnes. Une colonne occupe de 1 à 12 parts. container a une largeur max par breakpoint ; container-fluid prend 100 %.

⚠️ Attention : toujours container > row > col. Si la somme dépasse 12, la colonne passe à la ligne.
📌 À retenir : 12 colonnes ; col-md-6 = 6/12 à partir de md, 12/12 en dessous.

🔤Typographie, couleurs et arrière-plans

Titres h1-h6, display-1…6, lead, alignement text-center, poids fw-bold, casse text-uppercase, coupure text-truncate, couleurs text-* et fonds bg-*.

💡 Gardez une cohérence : primary = action principale, success = validation, danger = suppression.
📌 À retenir : Les classes text-* et bg-* portent un sens (sémantique), pas seulement une couleur.

📏Spacing (marges, paddings, gap)

Notation : {propriété}{côté}-{taille}. Propriété : m (margin), p (padding). Côtés : t b s e x y (s = début, e = fin). Tailles : 0-5 et auto. Responsive : p-md-5. Entre enfants flex/grid : gap-3.

📌 À retenir : Échelle 0 à 5 (0, .25, .5, 1, 1.5, 3 rem). ms/me remplacent ml/mr.

🔘Boutons et icônes

Variantes btn-primary…, contours btn-outline-*, tailles btn-lg / btn-sm, disabled, groupes btn-group, icônes avec Bootstrap Icons (<i class="bi bi-house">).

Icônes utiles : bi-speedometer2 dashboard · bi-person user · bi-gear settings · bi-search · bi-pencil edit · bi-trash delete · bi-house home · bi-box-arrow-right logout. Lien CSS : bootstrap-icons@1.11.3/font/bootstrap-icons.min.css.

📌 À retenir : Un bouton = btn + une variante.

🃏Cards

Une card = card > card-body > card-title / card-text. Elle sert de produit, profil, cours, blog, tarif ou statistique de dashboard.

📌 À retenir : h-100 aligne la hauteur des cartes d’une même ligne.

🧭Navbar

Le bouton hamburger (navbar-toggler) déclenche le plugin collapse via data-bs-toggle et data-bs-target : en dessous du breakpoint navbar-expand-lg, le menu se replie. Variantes : navbar-dark bg-dark, sticky-top, fixed-top.

📌 À retenir : navbar-expand-* choisit à partir de quand le menu est déplié.

📝Formulaires et validation

Champs : form-control, form-select, form-check, form-switch, input-group, form-floating. Validation : needs-validation novalidate + classe was-validated ajoutée au submit. Essayez d'envoyer le formulaire vide.

📌 À retenir : Validation native du navigateur + styles Bootstrap : pas besoin de JavaScript lourd.

📊Tables

table + table-striped (lignes alternées), table-hover, table-bordered, et table-responsive sur un conteneur pour le défilement horizontal sur mobile.

📌 À retenir : Sans table-responsive, un grand tableau casse la mise en page mobile.

🔔Alerts, badges, progress et spinners

📌 À retenir : alert-* pour informer, progress pour la progression, spinner-* pour l’attente.

🪟Modals

Un bouton avec data-bs-toggle="modal" et data-bs-target="#id" ouvre la fenêtre. data-bs-dismiss="modal" la ferme. Même principe pour confirmation, suppression, login ou détails produit.

📌 À retenir : Le modal est du HTML caché ; le bundle JS gère l’ouverture, le fond et la touche Échap.

🎠Accordion (FAQ) et Carousel

Remplacez les placeholders par des <img class="d-block w-100" alt="…"> libres de droits (Unsplash).

📌 À retenir : data-bs-parent force un seul panneau ouvert à la fois.

📐Utilities et Flexbox

Flex : d-flex, flex-row/column, justify-content-start|center|between|end (axe principal), align-items-* (axe transversal), flex-wrap, gap-*.

📌 À retenir : Charger le bundle avant la fin du body.

✨Animations

Principe : transitions (transition), transformations (transform) et @keyframes, en complément des classes Bootstrap (fade, progress-bar-animated, spinner-border).

💡 Animations courtes (150-400 ms), utiles, et désactivées avec prefers-reduced-motion.
📌 À retenir : Animer pour guider l’œil, pas pour décorer.

🎓Projet final : Student Management Dashboard

Sidebar, navbar, cartes de statistiques, table avec recherche et filtre, modal d'ajout, suppression avec confirmation, alerte, progress, footer, responsive (sidebar masquée sous md).

💡 Améliorations : modal « Modifier » (exercice), validation du formulaire, sauvegarde dans localStorage, puis branchement sur une API REST.
📌 À retenir : Séparez toujours structure (HTML), style (CSS) et comportement (JS).

✅Bonnes pratiques et erreurs fréquentes

Évitez le CSS inline, créez des composants réutilisables, pensez accessibilité (alt, aria-label, contrastes), performance (CSS minifié, import sélectif via npm) et hiérarchie visuelle claire. Ne copiez jamais du Bootstrap sans comprendre le CSS sous-jacent.
