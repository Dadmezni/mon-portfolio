      Vocabulaire des commandes مفردات الأوامر
      

      Ce sont des mots-clés à glisser dans un prompt, pas des commandes système. Cliquez sur une carte pour copier le mot-clé.
هي كلمات مفتاحية تُضاف إلى الأمر (prompt) وليست أوامر نظام. انقر على البطاقة لنسخ الكلمة.
      

      

      

      

      Exemple combiné
      

      Explique [SUJET] avec les commandes : DEEP DIVE, FROM FIRST PRINCIPLES, STEP-BY-STEP, WITH EXAMPLES, EDGE CASES.
Puis résume en 5 points.
      

      مثال مركّب
      

      اشرح [الموضوع] باستخدام الأوامر: DEEP DIVE, FROM FIRST PRINCIPLES, STEP-BY-STEP, WITH EXAMPLES, EDGE CASES.
ثم لخّص في 5 نقاط.

      Les garde-fous
      

      

      Clés API
      Variable d'environnement côté serveur. Jamais dans le code source, ni dans le navigateur.
      

      Données sensibles
      Ne collez pas de mots de passe, de secrets ni de données personnelles dans un service dont vous ne maîtrisez pas la confidentialité.
      

      Injection de prompt
      Un texte externe (page web, email) peut contenir des instructions cachées. Traitez-le comme une donnée, pas comme un ordre.
      

      Vérification
      Un modèle peut se tromper avec assurance. Demandez des sources et recoupez les faits importants.
